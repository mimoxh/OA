# 协作平台 OA 手机 App 使用说明（Android）

> 面向员工。App 不在应用商店上架，由公司 NAS 分发。管理员发布新版本的方法见 `docs/mobile/BUILD.md`。

## 1. 安装

支持 Android 8.0 及以上。纯血鸿蒙（HarmonyOS NEXT）不能安装 Android 应用，请用手机浏览器访问 OA。iPhone 暂无 App，同样用浏览器访问。

1. 用手机打开下载页 `https://<公司 OA 地址>/download/android`，或在电脑上打开同一地址，用手机扫页面上的二维码。电脑上的登录页底部也有「下载 Android App」链接。
2. 点「下载安装包」。浏览器提示「此类文件可能会损害设备」「无法安全下载」时，选「仍然下载」或「保留」。
3. 下载完成后点「打开」。提示条消失了的话，到浏览器菜单 →「下载内容」里点安装包。
4. 第一次安装时系统会提示「出于安全考虑，已禁止安装来自此来源的未知应用」：点「设置」，打开「允许来自此来源的应用」，返回后点「安装」。没有出现安装界面就再点一次安装包。
5. 安装完成后点「打开」。

各品牌手机的额外提示：

| 品牌 | 提示 | 处理 |
| --- | --- | --- |
| 小米 / 红米 | 「纯净模式」「安全守护」拦截 | 选「仍然安装」，或在设置里暂时关闭纯净模式 |
| 华为 / 荣耀 | 「纯净模式」拦截 | 选「仍然安装」，或在 设置 → 系统和更新 → 纯净模式 中暂时退出 |
| OPPO / 一加 / vivo / iQOO | 安装前的「安全检测」「应用安装验证」 | 选「继续安装」；部分机型需要输入账号密码确认 |

下载页底部列出了安装包和签名证书的 SHA-256 指纹，可以请管理员核对，确认安装包没有被替换。

## 2. 首次使用

1. 打开 App，在「服务器地址」里填公司 OA 地址（下载页的安装步骤里写着，例如 `https://oa.example.com`），点「连接」。
2. 用 OA 账号登录。登录状态保持 30 天：期间打开过 App 会自动顺延；距上次输入密码满 180 天需要重新登录。
3. 系统询问「是否允许发送通知」时选「允许」。
4. 通知栏会常驻一条「后台连接」通知，App 靠它在锁屏和退到后台时接收消息，不要关掉它。

切换到另一台服务器：「我的 → 切换服务器」，或长按桌面图标 →「切换服务器」。

## 3. 通知与电池设置（锁屏后收不到消息时）

到「我的 → 通知」：

- 「通知类别」：单聊、群聊、@我、审批与系统通知可以分别设置声音、横幅或关闭，点哪一类就打开系统里对应的设置。
- 「后台接收消息」保持打开，「连接状态」应显示「已连接，后台可接收」。
- 「忽略电池优化」点一下，在系统对话框里选「允许」。
- 「后台保活设置引导」按你的手机品牌列出了自启动、后台运行、省电策略的设置路径，照着打开。

国产手机默认会清理后台应用。不做这些设置时，锁屏一段时间后可能收不到提醒，打开 App 后会补上。

提醒规则：自己发的消息不提醒；免打扰的会话只在 @我 时提醒；电脑上正在使用 OA 时手机不响铃；在任一设备上看过的会话，手机上的通知会自动清除。

## 4. 升级

- App 启动和回到前台时会自动检查新版本。有新版本时弹出提示：点「立即更新」，App 用系统下载器下载安装包，下载完自动打开系统安装界面，点「更新」即可。点「稍后」则 24 小时内不再提示这个版本。
- 第一次在 App 内更新时，系统会要求允许「协作平台 OA」安装应用：点「去设置」，打开「允许来自此来源的应用」，返回 App 会自动继续安装。
- 管理员可以设置「最低支持版本」。低于它时提示框不能关闭，必须更新后才能继续使用（也可以「切换服务器」）。
- 也可以在「我的 → 检查更新」手动检查，或到下载页下载新版直接安装。
- 升级是覆盖安装，登录状态、服务器地址和通知设置都会保留。**升级时不要先卸载**，卸载会清掉这些设置。

## 5. 常见问题

| 问题 | 处理 |
| --- | --- |
| 连接失败 | 确认手机能上网，地址以 `https://` 开头且拼写正确；公司内网地址只能在连上公司 Wi-Fi 时使用 |
| 音视频通话按钮不可用 | 服务器地址是 `http://` 时系统不允许使用摄像头和麦克风，请管理员配置 HTTPS |
| 锁屏后收不到消息 | 按 §3 设置；「我的 → 通知」里连接状态不是「已连接」时，检查网络后重新打开 App |
| 更新时提示「与已安装的应用签名不一致」 | 手机上装的是测试版，先卸载再从下载页安装（卸载后需要重新填服务器地址和登录） |
| 更新下载失败 | 在提示框点「重试」，或「在浏览器下载」后按 §1 安装 |
| 下载的文件在哪里 | 手机的「下载 / OA」目录，下载完成后点系统通知即可打开 |

## 逐项说明

### 1. 横向溢出与评论占位文字

**测量方法**：每个页面加载后读取 `document.documentElement.scrollWidth`（下表的 sw）和 `innerWidth`（iw），sw > iw 即为溢出；同时找出右边界超出视口的元素，用来定位根因。

**根因**（按影响范围排序）：

1. **项目页进度条**：项目属性区的「进度」一栏是固定宽度 `w-72`（288px）的 `span`。属性区左列是 120px 的标签，手机上剩余宽度不到 288px，整页被撑到 400px（360px 视口）。项目页的所有视图（任务、里程碑、成员、统计）和任务详情都在这个页面里，所以都溢出。改为 `w-72 max-w-full`。
2. **财务日期筛选**：`<input type="date">` 在手机 WebView 上有较大的固有最小宽度，「开始 至 结束 查询」一行放不下，撑到 379px。日期框手机上改为 `max-md:w-0` + `flex-1`，由 flex 平分剩余宽度。影响收付款记录、记账凭证、科目余额三个页面。
3. **三列统计卡片**：收付款记录、供应商详情、发票详情的统计卡片是 `grid-cols-3`，长金额（如 ¥1,234,567.00）不能换行，把网格撑宽。手机上改为单列（`max-md:grid-cols-1`），`StatCard` 本身加 `min-w-0`、手机上缩小内边距和字号，并允许长数字断行。
4. **商机看板 / 任务看板的横向滚动容器**：容器用 `-mx-6` 抵消页面内边距，但手机上页面内边距是 `px-4`，多出 8px。手机上改为 `max-md:-mx-4 max-md:px-4`，商机看板另外加了按列吸附滚动。
5. 其他手机上偏挤的地方也一并处理：任务筛选条、任务详情的工时登记行（换行）、新建任务弹窗的字段网格、项目统计和成员视图（手机上是卡片）。

**评论占位文字**：桌面是「写评论，输入 @ 提及成员，Ctrl + Enter 发送」，手机上没有 Ctrl 键，而且文字太长会换成两行。新增 `commentPlaceholder(mobile)`，手机上显示「输入评论…」，桌面不变。单元测试 `tests/mobile/comment-placeholder.test.ts`。

### 2. 通讯录字母索引（微信式）

- **修复前**（第一轮的版本）：字母是 11px 的深灰色（`text-ink-2`），常驻时比较显眼。按住时有高亮和气泡，但有三个问题：
  - 字母由 `document.elementFromPoint` 取手指下方的元素得到。索引条只有 24px 宽，手指稍微偏出左右边缘就取不到字母，高亮和跳转都停住，看起来像「没反应」。
  - React 的 `onTouchMove` 是 passive 监听，不能阻止默认行为，拖动索引时整页可能跟着滚动。
  - 气泡是直接出现和消失的，没有过渡。
  - 说明：模拟器上精确按在字母上时，修复前也能看到高亮和气泡（`before/02-contacts-press-L-*.png`）。真机上「不像微信」的具体表现我们没有拿到录屏，以上是按代码和模拟器行为找到的差异。
- **做法**（`contacts/letter-index.tsx`）：
  - 平时：一列 10px 的浅灰字母（`text-ink-3`），没有成员的字母更淡，存在感很低。
  - 按住或上下滑动：手指所在的字母变成蓝色圆点高亮，屏幕中央出现 72px 的半透明深色方块，显示大号字母；列表同步跳到对应分组（没有成员的字母跳到其后最近的分组）。
  - 松手：高亮取消，气泡淡出消失。
  - 实现上在索引条上注册非 passive 的 `touchstart` / `touchmove`，按手指纵坐标换算字母（手指滑出索引条左右两侧也能继续跟随），并阻止页面跟着滚动。纵坐标到字母、字母到目标分组的换算放在 `src/lib/letter-index.ts`，单元测试 `tests/mobile/letter-index.test.ts` 覆盖越界夹取、空字母回退等情况。
  - 列表右侧留出 12px，索引条不再压住联系人行右边缘。
- **验证**（模拟器，手势和三键各一遍，用 `adb shell input motionevent` 发送系统级触摸）：在字母 L 上按下 → 索引条 `data-active=L`、气泡显示；向下拖到 W → `data-active=W`，列表滚到 W 组；松手 → 高亮取消、气泡隐藏。
- 截图：常驻状态 `before/02-contacts-gesture.png` → `after/02-contacts-gesture.png`（字母更小更浅）；按住 `before/02-contacts-press-L-gesture.png` → `after/02-contacts-press-L-gesture.png`；拖动和松手 `after/02-contacts-drag-W-gesture.png`、`after/02-contacts-release-gesture.png`；三键：`after/02-contacts-*-3btn.png`。

### 3. 工作台 6 个应用

**模块首页**：

- **修复前**：手机上 `/oa`、`/crm`、`/erp`、`/finance`、`/wms`、`/tms` 只显示一列模块菜单，看不到首页的概览数据。
- **修复后**：`ModuleShell` 的 `mobileRootContent` 默认改为开启，模块首页在手机上直接显示概览（统计卡片、图表、待办等）。页面标题下方新增子页面入口宫格（`ModuleEntries`，每行 4 个图标，按权限过滤，入口数据来自 `moduleSubPages()`，与桌面左侧二级导航同源）。桌面上宫格不渲染，桌面仍由左侧二级导航承担。
- 手机顶栏标题用 `mobileTitle` 显示模块名（如「ERP 企业资源」）。ERP 首页顶栏是 1 个主操作「新建销售单」+「更多」里的「新建采购单」，其他模块首页不超过 1 个按钮，符合第一轮「1 个主操作 + 更多」的规则。
- 返回：沿用第一轮的上级路由表，路由映射没有改，只更新了注释。按第一轮的规则，从模块首页入口进入列表页，返回回到模块首页；从工作台直接进入列表页，返回回到工作台；在模块首页按返回回到工作台。本轮没有在模拟器上重测返回键，列在复测清单第 8 项。

**列表页**：新增手机列表组件 `MobileList` / `MobileCard` / `MobileField`（`src/components/mobile/mobile-list.tsx`）。卡片第一行是标题和状态标签，第二行是编号或客户等副标题，第三行是关键字段，右侧是金额或数量；标题可换行，其余各行单行省略，不会撑出屏幕。桌面表格在手机上隐藏（`max-md:hidden`），桌面不受影响。

| WMS | 概览 + 入口 | 库存（卡片上带「流水」等操作）、入库、出库、库存流水 |
| TMS | 概览 + 入口 | 运单、车辆、司机 |

其余页面（审批、公告、日程、跟进、仓库、路线）本轮没有改动，只做了溢出测量，都不溢出。

单元测试 `tests/mobile/module-entries.test.ts` 覆盖子页面列表（不含首页本身、按权限过滤、未知模块）。

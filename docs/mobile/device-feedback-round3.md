## 逐项说明

### 1. 工作台（/work）手机布局

- **修复前**：问候语下面依次是收件箱、审批、公告、Web 完整版入口，然后是「应用」「待办」「最近编辑的文档」「应用概览」「最新公告」五个分区。待办在第二屏以下，三块待办竖着排，应用概览和最新公告与各模块首页、公告入口重复。
- **做法**：
  - 待办三块（待我审批、我的任务、今日日程）抽成一个数组，桌面和手机共用同一份内容。手机上用新组件 `TodoDeck` 放在问候语正下方：容器内横向滚动（`snap-x snap-mandatory`），每张卡片 `snap-start snap-always`，快速甩动也只翻一张；卡片宽 84%，右侧露出下一张约 70px；下方圆点指示当前是第几张，点圆点可以跳转。只有一块待办（例如只开了 PMS）时卡片占满宽度、不显示圆点。
  - 当前卡片的计算放在 `deckActiveIndex()`（`src/lib/swipe-deck.ts`）：按卡片步长取整；最后一张卡片比容器窄、对不齐起点，滚到最右端时直接算最后一张。
  - 横向滚动只发生在卡片容器内：容器用 `-mx-4 px-4` 贴到屏幕边缘，`overscroll-x-contain` 防止滑到头时带动页面，页面本身 `scrollWidth` 仍等于视口宽度。
  - 卡片下面就是「应用」网格（手机上标题间距由 40px 缩到 24px），再往下是收件箱、审批、公告、Web 完整版入口和「最近编辑的文档」。
  - 「待办」竖排分区、「应用概览」「最新公告」在手机上隐藏（`max-md:hidden`），桌面不变。
- **验证**（模拟器，两种导航结果相同）：
  - 分区只剩「应用 | 最近编辑的文档」，待办卡片在应用之前；页面 `scrollWidth` = `innerWidth` = 443。
  - 卡片 346px 宽，第二张从 374px 开始露出；用 `adb input swipe` 真实滑动两次，`scrollLeft` 0 → 358 → 650，当前卡片 0 → 1 → 2，圆点同步。修复过程中发现快速甩动会从第一张直接跳到第三张，加了 `snap-always` 后每次只翻一张。
  - 截图：`before/01-work-*.png` → `after/01-work-{gesture,3btn}.png`（初始）、`after/01-work-swipe1-*.png`（第二张）、`after/01-work-swipe2-*.png`（第三张）、`after/01-work-scroll*-*.png`（往下滚动）；测量数据在 `after/work-*.json`。

### 2. 「我的」去掉收件箱

- 「我的」页的入口改由 `meLinks({ isAdmin })` 生成：个人资料，管理员另有管理后台，不再有收件箱。

### 3. 通话、视频与其他全屏浮层的安全区

- **根因**：App 是沉浸式显示（WebView 画到状态栏和导航栏下面），页面靠 `body { padding-top: var(--sat) }` 和底部标签栏的 `padding-bottom: var(--sab)` 让出系统栏。但 `position: fixed` 的浮层以视口为准，不受 body 内边距影响。通话界面写的是 `fixed inset-x-0 bottom-0 top-app`（`top-app` 只是桌面客户端标题栏高度，手机上是 0），所以顶栏（会话名、计时、最小化按钮）压在状态栏下，底部控制栏（静音、视频、挂断）压在导航栏下。最小化浮窗 `bottom-5` 在三键导航下被导航栏盖住，还压住底部标签栏；来电浮窗距顶 20px，在状态栏里面。文档评论面板同样是 `fixed top-app`，标题和关闭按钮在状态栏下。
- **做法**（全部只在 `max-md:` 生效）：
  - 通话全屏界面 / 群会议：容器 `top-0 pt-[var(--sat)]`，深色背景仍铺满整屏；底部控制栏 `pb-[calc(var(--sab)+0.75rem)]`，高度改为自适应并允许换行（四个按钮在 443px 宽度下放不下一行，挂断换到第二行居中）。
  - 状态栏图标：通话全屏界面是深色，原来的深色状态栏图标几乎看不见。打开全屏界面时调用 Capacitor 内置的 `SystemBars.setStyle({ style: "DARK" })`（浅色图标），最小化或挂断后恢复 `DEFAULT`。不在 App 里时这个调用直接跳过，不需要原生改动。
  - 最小化浮窗：手机上移到右上角（`top: calc(var(--sat) + 6.75rem)`），在顶栏和会话页「视频通话进行中 · 回到通话」横条的下方，不挡底部标签栏、聊天输入框和导航栏。第一版放在顶栏正下方，截图发现会盖住「回到通话」按钮，于是又下移了 48px。
  - 来电浮窗：手机上左右各留 12px、距状态栏 12px（`top: calc(var(--sat) + 0.75rem)`）。
  - 文档评论面板：`top-0 pt-[var(--sat)] pb-[var(--sab)]`；数据表记录抽屉（`row-drawer.tsx`）同样处理；关系图弹窗的高度限制在 `100dvh - sat - sab - 1.5rem` 以内并按安全区居中。
  - 已检查无需修改：聊天记录搜索抽屉、PDF 预览、图片预览、任务详情（之前已处理安全区）、通用弹窗（距顶 12vh，高度 76vh，在系统栏以内）。
- **验证**：在模拟器上用无头 Edge 登录李娜作为对端，依次走呼出、接通、最小化、最小化后回到消息列表、来电、群视频会议，并打开文档评论、聊天搜索、PDF 预览，记录浮层内元素（顶栏、按钮、输入框）的位置。「内容最高点 / 最低点」是这些元素的最小 top 和最大 bottom；状态栏底边是 49，导航栏上边手势 962、三键 938。

  | 场景 | 修复前 手势 | 修复前 三键 | 修复后 手势 | 修复后 三键 |
  | --- | --- | --- | --- | --- |
  | 呼出 / 通话中（视频） | 0–969，6 个元素被挡 | 0–969，6 个被挡 | 50–950，0 | 50–926，0 |
  | 群视频会议 | 0–969，6 个被挡 | 0–969，6 个被挡 | 50–950，0 | 50–926，0 |
  | 最小化浮窗（会话页 / 消息列表） | 912–966，1 个被挡 | 912–966，4 个被挡 | 158–212，0 | 158–212，0 |

## 桌面回归

改动前（`3195baa` 的包）和改动后各构建一份 standalone，在同一份数据的两个副本上用无头 Edge 1440×900 以王芳登录，截图后逐像素对比（隔 2px 采样，`desktop/diff.txt`）：

- 工作台（顶部 / 底部）、收件箱、个人资料设置、文档、文档评论面板、日历、通话呼出全屏、最小化浮窗、来电浮窗、群会议：0 像素差异，或只有左侧栏未读角标和会话列表时间这几十个像素（两次运行之间新增的通话记录）。
- 「我的」页：去掉收件箱一行，有意的改动。
- 桌面截图用的是浮窗位置调整前的一版包；之后只改了最小化浮窗的一个 `max-md:` 类，桌面不受影响。
- 桌面上「接通后」的通话画面没有截到：无头 Edge 在双方接通后渲染进程崩溃（显示 This page couldn't load），改动前后的包都一样，与本次改动无关。接通前的全屏界面（`call2-outgoing`）已经覆盖了同一套布局，差异为 0。

## 小米真机复测清单

请分别在手势导航和三键导航（设置 → 桌面 → 系统导航方式）下各走一遍：

1. **工作台**：打开「工作」标签。问候语下方第一块就是「待我审批」卡片，右侧能看到下一张卡片的边缘；左右滑动，每次只翻一张（审批 → 任务 → 日程），下方圆点跟着变；点圆点能跳到对应卡片。整页上下滚动时不会左右晃动。卡片下方是「应用」，页面里没有「应用概览」和「最新公告」。
2. 工作台上的收件箱、审批、公告入口还在，点进去正常。
3. **我的**：只有「个人资料」（管理员另有「管理后台」）和 App 设置项，没有「收件箱」。
4. **语音 / 视频通话**：在单聊里发起视频通话。顶部会话名、计时和「最小化」按钮完整显示在状态栏下方，状态栏图标变成白色；底部的静音、视频、挂断按钮都在导航栏上方，能正常点击。
5. 点「最小化」：小浮窗出现在右上角（「视频通话进行中」横条下方，不盖住「回到通话」），不挡输入框和底部标签栏；切到消息列表后浮窗还在；点展开回到全屏，挂断后状态栏图标恢复深色。
6. **来电**：让同事呼叫你。来电浮窗在状态栏下方、左右留边，「拒绝」「接听」能点。
7. **群视频会议**：在群里发起视频通话，检查同第 4 条。
8. **文档评论**：打开任一文档，点右上角评论按钮，评论面板的标题和关闭按钮在状态栏下方，底部不被导航栏挡住。
9. 桌面浏览器打开工作台和通话界面，与之前一致。
